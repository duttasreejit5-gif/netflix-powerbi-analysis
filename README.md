# Netflix Content & IMDb Analytics — Power BI

## Project Overview

An interactive Power BI dashboard analyzing Netflix movies and TV shows using IMDb ratings, IMDb votes, runtime, release year, and age certification.

The project focuses on understanding content trends, audience engagement, runtime patterns, and certification-wise ratings.

## Dataset

The dataset contains **5,283 Netflix titles** covering movies and TV shows.

Key fields used in the analysis include:

- Title
- Type
- Release Year
- Age Certification
- Runtime
- IMDb Score
- IMDb Votes

## Tools Used

- Power BI
- Power Query
- DAX

## Business Questions

The dashboard answers the following questions:

1. Which movie and TV show perform best based on IMDb Score × IMDb Votes?
2. How has Netflix content distribution changed across release years?
3. How has the average IMDb score changed over time?
4. How has IMDb voting activity changed over time?
5. How has average runtime changed over the years?
6. How does age certification relate to IMDb ratings?

## Dashboard Pages

### 1. Netflix Overview

Provides an overall view of Netflix content, including:

- Total titles
- Movies vs TV shows
- Average IMDb score
- Average runtime
- Release-year trends
- Interactive filters for content type and release year

### 2. IMDb Analysis

Analyzes:

- IMDb score trends
- Average IMDb votes per title
- Top titles based on IMDb Score × IMDb Votes
- Relationship between IMDb score and IMDb votes

### 3. Runtime & Certification

Analyzes:

- Average runtime by release year
- Average IMDb score by age certification
- Distribution of titles by certification
- Certification-wise comparison between movies and TV shows

## Key Insights

- The dataset contains 5,283 Netflix titles.
- TV shows have a higher average IMDb score than movies.
- Movies have a substantially higher average runtime than TV shows.
- Netflix content is concentrated heavily in more recent release years.
- Rating alone may not be sufficient to identify the strongest titles, so IMDb Score × IMDb Votes was used as a combined metric.
- **Inception** ranks as the top movie using the Rating × Votes metric.
- **Breaking Bad** ranks as the top TV show using the Rating × Votes metric.
- PG-13 has the highest average rating among movies.
- TV-14 has the highest average rating among TV shows.
